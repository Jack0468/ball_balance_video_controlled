## Interpretation

- Run 2's top cluster (combined, shadow, autoaugment_proxy, photometric) beats its bottom cluster (baseline, blur, occlusion, geometric_jitter) consistently across all 5 seeds. Within each cluster, the spread is smaller than 1 std dev — no strict ordering is supported within a cluster.
- `geometric_jitter`: 33.2px (Run 1, full scale) vs. 54.4px ± 9.8 (Run 2, reduced scale) vs. 32.8px (Run 3, full scale repeat). Run 3 confirms Run 1, not Run 2 — the poor Run 2 showing is a training-budget artifact (200 rows / 3 epochs insufficient for this variant to converge), not evidence of a weak augmentation.
- At full training scale (600 rows / 8 epochs), the ranking is: photometric < autoaugment_proxy < geometric_jitter < shadow < combined < baseline (best to worst by ball px error). Photometric-only and shadow-containing variants are the most consistently strong performers across both scales tested.
- `baseline` (no augmentation) is the clear worst performer at full scale (Run 1: 52.4px, ~1.6-1.9x every augmented variant), but only mid-pack at reduced scale (Run 2: 50.0px ± 10.2, high variance) — augmentation's benefit is more pronounced with more training budget in this data.
